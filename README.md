# 六边形战棋 Web Demo

一个**零依赖、浏览器直接打开即可运行**的六边形回合制战棋 Demo。玩法与数值参考《某二战题材slg战棋单位设计.xlsx》与《某二战题材SLG战棋策划案》（16 种兵种、完整伤害公式、穿甲/士气/主动性机制）。

## 运行

直接双击 `index.html`（file:// 即可，无需服务器/构建/联网），或用任意静态服务器：

```
npx serve .        # 或 python -m http.server
```

## 操作

1. 点击己方单位选中——**黄色**高亮自己，**绿色**为可移动格，**红色**为可攻击目标。
2. 点绿格 → 移动；点红格 → 攻击（自动结算反击）。
3. **鼠标悬浮在任意单位上**（敌我都行）可查看完整属性信息。
4. 移动到敌方「城」格 → 占领。
5. **左侧「经济」面板**：显示征召令/钢铁；点击我方城镇查看可生产单位——**城市产步兵、工厂产坦克/火炮**（消耗钢铁）；点击生产按钮后选绿色格子部署新单位。
6. 点右上「结束回合」→ 敌方 AI 行动后回到你的回合（城镇每回合自动产出资源）。
7. **右侧「棋谱」窗口**记录每步操作：回合切换有醒目蓝色标题（`━━━ 回合 N · 玩家回合 ━━━`），**单位被消灭**（红色加粗 `💀 消灭！`）与**区域被占领**（金色加粗 `🏁 占领！`）单独突出，另有移动/攻击/士气/产出/生产/二次移动记录，每条带回合数。
8. 胜利条件：**占领敌方城市所在区域**（消灭敌军不算结束游戏）；失败：我方全灭或超过回合上限。
9. 顶栏「重新开始」可随时快速重开本局。

## 自检

```
node test.js
```

headless 验证：数据加载、六边形几何、伤害公式黄金值（基础步兵对基础步兵 **攻击 36~46、反击 27~34.5**，与策划 xlsx sheet「伤害计算」一致）、穿甲/主动性查找、地图初始化与回合状态。

## 数据驱动（改数据 = 改游戏）

所有数值都在 `js/data.js`，改数值即改游戏，无需改逻辑：

- **单位** `UNITS`：id → 定义（hp 血量 / attack 攻击 / defense 防御 / move 移动 / initiative 主动性 / armor 装甲 / anti_armor 反装甲 / range_min·range_max 射程 / attack_method 攻击方式 / category 兵种）。
- **地形** `TERRAINS`：id → 定义（move_cost 移动消耗，-1=不可通行 / defense_bonus 防御加成 / color 显示色 / foot_only 仅步兵可通行 / capturable 可占领）。
- **攻击倍率** `ATTACK_METHODS`、**穿甲** `ARMOR_PEN_RULES`、**主动性** `INITIATIVE_RULES`、**士气** `MORALE`：均为查找表。
- **建筑（城镇）** `BUILDINGS`：类型 → 定义（`produces` 产出资源类型 recruit/steel/air、`can_produce` 可生产单位列表、`levels[等级].income` 每回合产出）。

示例关卡在 `js/game.js` 的 `LEVEL`（地形字符画 + 单位/建筑部署 + 目标），可照此新增关卡。

> 数据由 Godot 版 `ww2/data/*.json`（源自 xlsx）转换而来；改动数值建议改 `data.js`，或改 xlsx 后重新转换（见 `ww2/tools/import.ps1`）。

## 伤害公式（参考策划案）

```
攻击伤害 = MAX(攻击×攻方士气×攻击效果倍率 − 防御×守方士气, 40) × 穿甲倍率 × 随机数
反击伤害 = MAX(攻击×攻方士气×攻击效果倍率×主动性倍率 − 防御×攻方士气, 30) × 穿甲倍率 × 随机数
随机数   = 0.9 + 0.25×rand()（再叠加攻方士气随机数基数影响）
```

**士气**（**每个单位移动后**按新位置立即判定，玩家与敌方一致；按被围程度分档）：
- 一对对边夹击 / 邻格敌军 3 个以上 → **低落**（攻防 ×0.8，正常移动）；
- **两组对边**被敌军占据（如东+西 且 东南+西北）→ **受困**（攻防 ×0.6，**保留 1 格移动**）；
- 6 个邻格全为敌军（完全包围）→ **混乱**（攻防 ×0.5，无法移动）。

**二次移动**：坦克/装甲单位（载具）**消灭敌军后**获得**一半基础移动力**，可再移动一次（已攻击过，不能再攻击）。
